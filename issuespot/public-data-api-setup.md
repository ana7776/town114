# 공공데이터 API 연동 메모

## 사용하는 환경변수

- `PUBLIC_DATA_SERVICE_KEY`: 공공데이터포털에서 발급받은 일반 인증키 또는 Encoding 인증키

## Cloudflare Pages 설정

1. 공공데이터포털에서 아래 API를 활용신청합니다.
   - 금융위원회_실손보험정보
   - 금융위원회_자동차보험 피해자 통계정보
2. Cloudflare 대시보드에서 Workers & Pages > issuespot > Settings > Environment variables로 이동합니다.
3. Production 환경에 `PUBLIC_DATA_SERVICE_KEY`를 Secret 또는 encrypted variable로 추가합니다.
4. Pages를 다시 배포합니다.

## 사이트 내부 호출 주소

- `/api/public-data/silson-insurance`
- `/api/public-data/auto-victim`
- `/api/public-data/silson24-hospitals`

예시:

```text
/api/public-data/silson-insurance?likeCmpyNm=삼성&numOfRows=5
/api/public-data/auto-victim?basYm=202406&numOfRows=5
/api/public-data/silson24-hospitals?startDateTime=20250113000000&endDateTime=20250113235959&numOfRows=5
```

인증키는 Worker에서만 사용하며 브라우저 응답에는 노출하지 않습니다.

## 추가 활용신청 추천 순서

이슈스팟 사이트 주제와 바로 연결되는 순서입니다.

1. 보험개발원_실손24 참여 요양기관 안내 서비스
   - 활용 위치: 실손24 청구 전 확인 글, 병원 서류 안내 글
   - 활용 이유: 실손24 참여 요양기관의 명칭, 주소, 종별코드 등을 조회할 수 있어 독자가 실손24 가능 여부를 확인하는 흐름에 맞습니다.

2. 우체국금융개발원_우체국보험 보험금 청구 구비서류
   - 활용 위치: 보험금 청구 구비서류 글
   - 활용 이유: 청구사유, 발생원인구분, 기본서류, 추가서류 항목이 있어 청구서류 체크리스트로 쓰기 좋습니다.

3. 금융위원회_금융통계생명보험정보
   - 활용 위치: 보험사 자료실, 보험사별 참고 정보
   - 활용 이유: 생명보험사의 일반현황, 재무현황, 주요경영지표, 주요영업활동을 조회할 수 있습니다.

4. 금융위원회_금융통계손해보험정보
   - 활용 위치: 보험사 자료실, 손해보험사 참고 정보
   - 활용 이유: 손해보험사의 일반현황, 재무현황, 주요경영지표, 주요영업활동을 조회할 수 있습니다.

5. 건강보험심사평가원_약국정보서비스
   - 활용 위치: 약제비 영수증, 약국 서류 안내 글
   - 활용 이유: 약국명, 주소 등 약국 기본 정보를 확인하는 보조 자료로 쓸 수 있습니다.

6. 건강보험심사평가원_의료기관별상세정보서비스
   - 활용 위치: 병원 서류 발급 안내, 진료과목별 서류 안내 글
   - 활용 이유: 의료기관 시설, 진료과목, 장비, 전문병원 지정 등 상세 정보를 제공합니다.

7. 건강보험심사평가원_병원정보서비스
   - 활용 위치: 병원명 검색, 병원 서류 안내 글
   - 활용 이유: 의료기관 기본 목록을 먼저 찾고, 의료기관별상세정보서비스와 연결할 때 필요합니다.

우선 신청은 1번부터 4번까지를 추천합니다. 5번부터 7번은 사이트에서 병원·약국 검색 기능까지 확장할 때 붙이면 좋습니다.
